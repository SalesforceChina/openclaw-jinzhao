# 🎉 Mac 安装 QClaw 小龙虾完全指南

> 适用对象：Mac 用户 | 产品：QClaw（腾讯电脑管家团队出品）| 难度：⭐

---

## 📚 在开始之前，先了解一下

### 什么是 QClaw？

**QClaw** 是腾讯电脑管家团队基于 OpenClaw 开源生态深度封装的本地 AI Agent 助手，昵称「小龙虾」。

### QClaw vs 原版 OpenClaw

| 对比项 | QClaw（腾讯版） | 原版 OpenClaw |
|--------|----------------|---------------|
| 安装难度 | **一键安装**，20秒完成 | 需要配置 Node.js、Git 等环境 |
| 配置 | **零配置**，开箱即用 | 需要手动配置各种参数 |
| 微信连接 | **扫码直连**，微信里发指令 | 需要手动配置渠道 |
| 数据安全 | 本地运行，不上云 | 本地运行，不上云 |
| 技能 | 预置 5000+ 技能 | 需要自己安装 |

### 核心功能

- ✅ **一键安装**：20 秒完成安装，三步上手
- ✅ **本地隐私安全**：模型推理、数据处理都限定在本机，不上云
- ✅ **微信直连**：扫码绑定后，可在微信里发指令
- ✅ **Skills 丰富**：接入 ClawHub/GitHub 等平台，技能数超过 5000 个

## 🧰 准备工作

### 需要准备的东西

1. ✅ 一台 Mac 电脑（macOS 10.15 或更高版本）
2. ✅ 网络连接
3. ✅ 一个 AI 模型 API Key（QClaw 内置部分免费额度）

---

## 📥 安装步骤

### 方法一：官网下载（推荐）

1. 打开浏览器，访问腾讯电脑管家官网或 QClaw 下载页面
2. 下载 Mac 版本的 QClaw 安装包（.dmg 文件）

### 方法二：从腾讯云获取

访问腾讯云开发者社区，搜索「QClaw」获取下载链接。

---

## 📥 安装 QClaw

### 第一步：安装应用

1. 双击下载好的 **`.dmg`** 文件
2. 将 QClaw 图标拖拽到 **Applications** 文件夹
3. 等待拖拽完成

### 第二步：启动 QClaw

1. 在「启动台」或「应用程序」中找到 **QClaw**
2. 点击启动

### 第三步：扫码绑定微信

1. QClaw 启动后会显示一个 **二维码**
2. 打开手机微信，扫描二维码
3. 确认授权绑定

📌 **提示**：绑定微信后，你就可以在微信里直接给 QClaw 发指令了！

---

## 💬 使用技巧

### 在 Mac 上直接对话

直接在 QClaw 输入框输入你的问题或指令，例如：

- 「帮我写一封邮件」
- 「总结一下这个文档」
- 「帮我查一下今天的天气」

### 在微信里远程控制

绑定微信后，你可以在微信里给 QClaw 发消息：

- 「帮我打开浏览器」
- 「把桌面上的文件整理一下」
- 「帮我写一份报告」

---

## ⚙️ 配置 AI 模型（可选）

虽然 QClaw 有免费额度，但你也可以配置自己的 API Key 来解锁更多功能：

1. 点击 QClaw 界面右上角的「设置」
2. 选择「模型配置」
3. 选择你想要的模型（支持 MiniMax、Kimi、DeepSeek 等）
4. 输入你的 API Key

## ❓ 常见问题

### 问题 1：安装后打不开？

**解决方法**：
1. 检查是否已经把 QClaw 拖拽到 Applications 文件夹
2. 尝试在「系统偏好设置」→「安全性与隐私」中允许运行
3. 重启电脑后再试

### 问题 2：微信扫码失败？

**解决方法**：
1. 确保手机微信已登录
2. 确保手机网络正常
3. 尝试刷新二维码重新扫码

### 问题 3：技能没有触发？

**解决方法**：
1. 检查技能是否已启用
2. 尝试用更具体的指令触发技能
3. 查看技能说明了解正确的触发方式

### 问题 4：Mac 提醒「无法验证开发者」？

**解决方法**：
1. 打开「系统偏好设置」
2. 进入「安全性与隐私」
3. 点击「仍要打开」
