### 1.1 认识你的AI助手团队

#### OpenClaw 是什么？

想象一下，你雇佣了一个全能助理团队，这个团队可以帮你处理各种创作任务：写文案、做设计、找素材、排版发布……OpenClaw 就是这样一个"数字助理团队"。

**通俗解释：**
OpenClaw 就像你的"私人创作工作室"，里面有各种专业工具和助手。你只需要告诉它你想要什么（比如"帮我写一篇关于春季护肤的文章，配上美图"），它就会自动完成所有工作。

**核心优势：**
- **24小时待命**：随时响应你的需求
- **多技能精通**：文字、图片、视频、排版样样在行
- **学习能力强**：越用越懂你的风格
- **效率极高**：几分钟完成人工几小时的工作

- **个性化设置**：按你的喜好调整参数
- **权限管理**：控制哪些功能可以访问

**配置文件位置：**
```
~/.openclaw/extensions/baoyu/EXTEND.md
```

#### OpenClaw 定时任务（Cron）设置详解

##### 什么是 Cron？（用大白话解释）

**通俗解释：**
Cron 就像你手机的"闹钟"或"定时任务"。你设置好时间（比如每天早上8点），到时间它就自动执行某个任务。

**例子：**
- 闹钟：每天7点响 → Cron：每天7点执行"响铃"
- 定时发微博：每天12点发 → Cron：每天12点执行"发微博"
- 热点监控：每天9点、14点、20点检查 → Cron：每天三个时间点执行"检查热点"

**Cron表达式格式：**
```
* * * * * 要执行的命令
│ │ │ │ │
│ │ │ │ └── 星期几 (0-6，0=周日)
│ │ │ └──── 月份 (1-12)
│ │ └────── 日期 (1-31)
│ └──────── 小时 (0-23)
└────────── 分钟 (0-59)
```

**常见例子：**
- `0 9 * * *`：每天9:00执行
- `0 14,20 * * *`：每天14:00和20:00执行
- `0 9 * * 1`：每周一9:00执行
- `*/30 * * * *`：每30分钟执行一次

##### 如何设置每天定时推送热点

**完整设置步骤：**

**第一步：创建热点监控脚本**
```
在OpenClaw对话中输入：

创建热点监控任务，每天上午9点、下午2点、晚上8点自动扫描热点并推送到飞书
```

**第二步：AI生成配置代码**
AI会生成类似这样的配置：

```yaml
# 热点监控配置 (hotspot_monitor.yaml)
name: "每日热点监控"
schedule: "0 9,14,20 * * *"  # 每天9点、14点、20点执行
task: "hotspot_monitor"
channels:
  - feishu  # 推送到飞书
  # - wechat  # 也可以推送到微信（需要配置）
sources:
  - weibo  # 微博热搜
  - zhihu  # 知乎热榜
  - douyin  # 抖音热榜
  - bilibili  # B站热门
  - xiaohongshu  # 小红书热榜
  - baidu  # 百度热搜
filters:
  min_hotness: 50  # 最低热度值
  match_keywords:  # 匹配你的领域关键词
    - "美妆"
    - "护肤"
    - "穿搭"
    - "生活方式"
    - "健康"
output_format: "markdown"  # 输出格式
```

**第三步：保存并激活配置**
```
在OpenClaw对话中输入：

保存热点监控配置并立即测试一次
```

AI会执行：
1. 保存配置文件到指定位置
2. 注册定时任务
3. 立即执行一次测试
4. 发送测试结果给你确认

#### 流量预测方法

##### 简单预测模型

**热度增长曲线分析：**
```
预测公式：
爆款概率 = 基础热度 × 增长速率 × 话题潜力

其中：
- 基础热度：当前阅读/播放量
- 增长速率：过去2小时增长率
- 话题潜力：季节性、争议性、实用性评分
```

**实际计算示例：**
```
话题：#春季护肤攻略#
当前热度：500万阅读
2小时前：300万阅读
增长率：(500-300)/300 = 66%
季节性评分：0.9（春季刚需）
实用性评分：0.8
争议性评分：0.3（低争议）

爆款概率 = 500 × 0.66 × (0.9+0.8+0.3)/3
         = 500 × 0.66 × 0.67
         ≈ 221

标准化后：221/300 × 100% = 74%
```

#### 与账号定位匹配度的判断

##### 匹配度评分系统

**五个维度评分（每项0-1分）：**

1. **主题匹配度**：
   - 完全相关：1分（如美妆博主看到美妆热点）
   - 部分相关：0.5分（如美妆博主看到护肤热点）
   - 不相关：0分（如美妆博主看到体育热点）

2. **受众匹配度**：
   - 你的粉丝会感兴趣：1分
   - 部分粉丝会感兴趣：0.5分
   - 粉丝不感兴趣：0分

3. **内容形式匹配度**：
   - 适合你的内容形式（图文/视频）：1分
   - 需要调整形式：0.5分
   - 完全不适合：0分

4. **创作难度匹配度**：
   - 你能轻松创作：1分
   - 需要学习/准备：0.5分
   - 超出能力范围：0分

5. **商业价值匹配度**：
   - 可直接变现：1分
   - 间接提升影响力：0.5分
   - 无商业价值：0分

**计算公式：**
```
总匹配度 = (主题×0.3 + 受众×0.3 + 形式×0.2 + 难度×0.1 + 商业×0.1)

优秀：> 0.8
良好：0.6-0.8
一般：0.4-0.6
较差：< 0.4
```

##### 实际判断示例

**案例：美妆博主看到热点 #春日樱花妆#**

```
评分：
1. 主题匹配度：1.0（完全相关）
2. 受众匹配度：0.9（粉丝喜欢妆容教程）
3. 内容形式匹配度：1.0（适合做图文/视频教程）
4. 创作难度匹配度：0.8（需要准备化妆品）
5. 商业价值匹配度：0.7（可推荐化妆品）

总匹配度 = 1.0×0.3 + 0.9×0.3 + 1.0×0.2 + 0.8×0.1 + 0.7×0.1
         = 0.3 + 0.27 + 0.2 + 0.08 + 0.07
         = 0.92（优秀）

结论：强烈建议跟进！
```

**案例：美妆博主看到热点 #新能源汽车#**

```

总匹配度 = 0.1×0.3 + 0.2×0.3 + 0.3×0.2 + 0.1×0.1 + 0.1×0.1
```

#### 选题评分系统

##### AI 自动打分的标准

**评分维度（每项0-10分）：**

1. **热度潜力分**（权重30%）
   ```
   计算公式：
   基础分 = log10(初始热度) × 2
   趋势加分：快速上升+3，平稳增长+1，缓慢下降-1
   季节性加分：符合当前季节+2
   
   示例：
   初始热度500万，log10(5000000)≈6.7，基础分=13.4
   快速上升+3，春季选题+2
   总分=18.4 → 标准化到10分制：9.2分
   ```

2. **受众匹配分**（权重25%）
   ```
   根据你的粉丝画像计算：
   - 年龄匹配度：0-2分
   - 性别匹配度：0-2分
   - 兴趣匹配度：0-3分
   - 历史偏好匹配度：0-3分
   
   示例：
   你的粉丝：18-35岁女性，喜欢美妆教程
   选题：学生党平价彩妆
   年龄匹配：2分（完美匹配）
   性别匹配：2分（女性向）
   兴趣匹配：3分（美妆相关）
   历史偏好：2分（过往类似内容表现良好）
   总分=9分
   ```

3. **创作可行性分**（权重20%）
   ```
   - 资源可得性：0-4分（是否有产品、设备等）
   - 技术难度：0-3分（拍摄、剪辑、写作难度）
   - 时间可行性：0-3分（能否在热点期内完成）
   
   示例：
   资源可得性：3分（有样品，缺模特）
   技术难度：2分（需要学习新剪辑技巧）
   时间可行性：2分（需要3天，热点期5天）
   总分=7分
   ```

4. **商业价值分**（权重15%）
   ```
   - 直接变现可能：0-4分（广告、带货）
   - 品牌合作可能：0-3分（品牌赞助）
   - 长期价值：0-3分（成为系列、建立专业形象）
   
   示例：
   直接变现：3分（可带相关产品）
   品牌合作：2分（可能有品牌感兴趣）
   长期价值：2分（可做成系列）
   总分=7分
   ```

5. **差异化分**（权重10%）
   ```
   - 创新性：0-4分（新角度、新形式）
   - 竞争程度：0-3分（同类内容多少）
   - 你的优势：0-3分（你的独特视角）
   
   示例：
   创新性：2分（常见主题新角度）
   竞争程度：1分（很多类似内容）
   你的优势：3分（你有专业背景）
   总分=6分
   ```

**总分计算公式：**
```
总分 = 热度潜力×0.3 + 受众匹配×0.25 + 创作可行×0.2 + 商业价值×0.15 + 差异化×0.1

评分标准：
9-10分：S级（必须做）
7-8.9分：A级（优先做）
5-6.9分：B级（可选做）
<5分：C级（暂不考虑）
```

##### 优先级排序方法

**自动排序规则：**

1. **紧急程度排序**：
   ```
   如果 热度趋势 = "快速上升" 且 爆款概率 > 80%
   则 优先级 = P0（今天必须开始）
   
   如果 计划发布时间 - 今天 < 3天
   则 优先级 = P0或P1
   ```

2. **综合评分排序**：
   ```
   按总分降序排列
   同分情况下：
   - 热度潜力分高的优先
   - 创作可行性分高的优先
   - 商业价值分高的优先
   ```

3. **资源约束排序**：
   ```
   考虑你的实际资源：
   - 时间有限：选择预计时长短的优先
   - 预算有限：选择所需资源少的优先
   - 能力有限：选择技术难度低的优先
   ```

**实际排序示例：**
```

1. 春季护肤攻略（总分8.5，预计时长4h，热度快速上升）
```

```
1. 敏感肌成分红黑榜
2. 医院皮肤科医生访谈
3. 敏感肌产品长期实测
4. 不同敏感类型细分方案
```

##### 角度二：专业 vs 亲民

**竞品做法**：过于专业，术语难懂
**你的差异化**：专业但易懂，用比喻解释

**示例：**
```
竞品：讲解「烟酰胺的作用机制」
你：用「皮肤的小保安」比喻烟酰胺

差异化表达：
- 不说「抑制黑色素转运」
- 说「拦住想去捣乱的黑色素小坏蛋」
- 不说「促进角质层更新」
- 说「帮老旧细胞退休，让新细胞上岗」
```

##### 角度三：结果 vs 过程

**竞品做法**：只展示完美结果
**你的差异化**：展示真实过程，包括失败

**示例：**
```
竞品：完美妆容教程（一次成功）
你：真实跟妆过程（包括失误和修改）

差异化内容：
1. 第一次尝试的翻车现场
2. 请教专业人士后的改进
3. 不同光线下的效果对比
4. 持妆8小时的真实状态
```

##### 角度四：单品 vs 组合

**竞品做法**：单个产品测评
**你的差异化**：组合方案推荐

**示例：**
```
竞品：A面霜测评、B精华测评、C防晒测评
你：春季干皮早晚护肤组合方案

差异化内容：
1. 早上：清爽组合（水+精华+防晒）
2. 晚上：修护组合（油+面霜+面膜）
3. 特殊情况：过敏期急救组合
4. 预算分级：平价/中端/高端组合
```

##### 角度五：跟随 vs 引领

**竞品做法**：跟随热点
**你的差异化**：创造热点

**示例：**
```
竞品：做大家都在做的「樱花妆」
你：创造新的「新中式妆容」

差异化做法：
1. 结合传统文化元素
2. 设计专属标签（如#新中式妆容挑战）
3. 发起互动活动
4. 联合其他创作者推广
```

#### 总结：从竞品分析到自己的选题

**完整转化流程：**

```
竞品爆款 → 分析要素 → 提取灵感 → 结合自身 → 创造选题
```

**具体步骤：**

1. **收集**：监控竞品爆款内容
2. **分析**：拆解成功要素（标题、结构、视觉、互动）
3. **归类**：按主题、形式、平台分类
4. **评估**：哪些适合你，哪些需要调整
5. **创新**：结合你的特色，加入新元素
6. **测试**：小范围测试，收集反馈
7. **优化**：根据数据持续改进

**避免的坑：**

1. **不要直接抄袭**：借鉴思路，不是复制内容
2. **不要盲目跟风**：选择符合你定位的热点
3. **不要贪多求全**：专注1-2个方向做深
4. **不要忽略数据**：用数据验证假设
5. **不要停止学习**：竞品也在进步，持续观察

**最终目标：**

通过竞品分析，你要达到：

1. **了解市场**：知道什么内容受欢迎
2. **找到差距**：发现你和竞品的差异
3. **发现机会**：找到市场空白点
4. **建立优势**：形成你的独特价值
5. **持续优化**：不断改进内容策略

> **重要提示**：竞品分析是手段，不是目的。最终要回归到为你的粉丝创造价值。
